# CPT Hours

Home-screen iPhone app (PWA) for the private `cpt_agent` GitHub Actions bot that submits the
weekly BUS-799 Work Hour Log to Canvas.

- Hosted with GitHub Pages: https://vishin10.github.io/cpt-app/
- Contains no secrets or personal data. The app reads `state.json` from the private
  `cpt_agent` repo with an access key that is stored only on the phone.
