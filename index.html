One-time setup

Paste a GitHub access key so this app can read your agent and press its buttons.

  1. Open GitHub → New fine-grained token
  2. Name: CPT app · Expiration: up to 1 year
  3. Repository access: Only select repositories → cpt_agent
  4. Permissions: Actions: Read and write, Contents: Read-only
  5. Generate, copy, paste below

The key stays only on this phone.

To get notifications: tap Share → Add to Home Screen, then open CPT Hours from your home screen.
